# PLAN.md — 매일 아침 AI 기업 소식 블로그

## 과제

매일 아침 AI 기업(Google · Anthropic · OpenAI) 공식 사이트의 새 글을 찾아, 뉴스레터처럼 읽히는 글 한 편으로 내 블로그에 올린다.

## 핵심 세 줄

- 조건: 날마다 결과가 다른 웹서치로 찾은 글을, 원문과 어긋나지 않게, 내가 확인한 것만 매일 아침 올린다.
- 해결할 문제: 사람이 매일 찾고 쓰고 대조하던 일을 맡기면서도, 틀린 글이 내 이름으로 나가지 않게 한다.
- 할 일: 수집 → 작성 → 검사 → 승인 → 게시를 graph 로 적고, 새 글이 없는 날은 PR 없이 끝낸다.

## 조건마다 반영할 것

| 조건 | 반영할 설정 · 파일 | graph 의 단계 |
|---|---|---|
| ① 매일 아침 저절로, 같은 날 두 번 올라가면 안 된다 | GitHub Actions 의 정해진 시각 실행(cron 식) · run ID · lock — `.github/workflows/` | graph 밖 |
| ② 새 글은 웹서치로 찾고, 결과는 날마다 다르다 | 가져온 원문 · 주소 · 게시일 · 가져온 날짜를 실행마다 `runs/<날짜>/` 에 남긴다 | collect |
| ③ 숫자 · 인용은 원문과 같아야 한다 | 원문 대조 검사 — 원문과 같은지까지, 사실 자체의 검증은 아니다 | check |
| ④ 틀린 초안은 다시 쓰되 끝없이 쓰지 않는다 | `max_attempts` · `retry_prompt` · human queue — `graph.yaml` | check → write |
| ⑤ 내가 확인한 글만 블로그에 나간다 | PR 승인, 합치면 GitHub Pages 가 `docs/` 를 올린다 | approve |
| ⑥ 새 글이 없는 날과 수집이 실패한 날은 다르다 | 새 글 0건은 exit code 4 로 PR 없이 끝, 수집 실패는 다시 시도하고 넘친 일은 human queue | count |
| ⑦ 내 독자와 말투 기준 하나 | `CLAUDE.md` 의 독자 · 말투 · 하지 말 것 | write |
